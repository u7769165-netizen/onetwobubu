# 一二 & 布布 · 双人合作闯关

治愈系情侣向 2D 横版解谜（森林冰火人风格）。两名玩家分别操控「一二」（冰/水属性）与「布布」（火属性），利用属性克制与协作机关，让两人同时抵达出口过关。纯前端实现，无构建工具、无第三方运行时依赖。

---

## 玩家：怎么开始玩

**启动**（任选其一）

- 双击 `启动游戏.bat`
- 或命令行：`node server.js`，然后浏览器打开 http://localhost:8765

> 需本机已安装 Node.js（提供静态服务与联机通道）。单人进度存浏览器 localStorage，登录账号后自动双向同步云端（换设备不丢进度）。

**按键**

| 角色 | 左 | 右 | 跳 |
|---|---|---|---|
| 一二（蓝） | `A` | `D` | `W` |
| 布布（橙） | `←` | `→` | `↑` |

通用：`R` 重开本关 · `Esc` / `P` 暂停或继续 · `T` 切换移动形象（侧面皮肤）。

**触屏操控**（手机 / 平板）：游戏界面自动显示虚拟按键——左下 ◀▶ 方向、右下 ⬆ 跳跃、左上 ⏸ 暂停、跳跃键上方 🔄 换角色（单人本地切换控制一二/布布；联机时固定控制本端角色自动隐藏）。支持多指同按（方向+跳跃）。显示策略在设置界面「📱 触屏按键」调整：自动（触屏设备显示）/ 总是显示 / 关闭。建议横屏游玩。

**核心规则**

- 水池只有一二能走，岩浆只有布布能走，毒液两人都怕；碰到即重生。
- 收集甜品（🍰 归一二、🧋 归布布）与 💗 爱心水晶，按用时/收集/死亡数评 S~C。
- 协作机关：弹跳台需两人同站蓄力共跳、Boss 需按属性轮流破核；恋爱终章新机关——同心连压板（两人各踩一块开金门）、心之桥（牵手距离才实体化）、平衡升降台（双人同站才上升）、节奏火墙（全局同拍，看预警穿越）。
- 23 个主关卡共 40 层，逐层解锁；通关解锁「合照」，恋爱空间有好感度/任务/纪念册长线系统。
- 💕 恋爱终章：爱之圣殿后的 4 个隐藏章节（心之回廊 / 默契圣殿 / 双生之塔 / 永恒之约）需好感度达 340 / 520 / 760 / 1060 方可进入，每层首通额外 +15 好感。
- 移动形象皮肤：设置界面或游戏内 `T` 键可切换「经典 / 郊游」两套侧面移动贴图（正面形象不变），移动时脚部自动迈步。
- 背景音乐选曲：设置界面「🎧 背景音乐」下拉二选一——「🐼 一二布布专属bgm」（7 首顺序播放，不含原版，末首播完回到第一首）/「🎼 原版经典旋律」（原版单曲循环）；切换时交叉渐变平滑过渡。

**双人联机**（需登录账号；同一局域网，或一方暴露地址）

1. 双方各自点「双人联机」→ 注册/登录账号（见下节）。
2. 玩家 A 点「联机」→「创建房间」，得到 4 位房间码。
3. 玩家 B 点「联机」→ 填服务器地址（默认 `ws://<A的局域网IP>:8765/ws`）+ 房间码 → 加入。
4. A 操控一二、B 操控布布，双方画面实时同步。主机为权威端。

> 未登录点击「双人联机」会先弹登录界面；建房/加入请求经服务器鉴权，游客凭证会被拒回（`needauth`）。单人模式无需账号。

## 账号与云存档

**注册/登录**：主界面右上「👤 登录账号」或点「双人联机」进入。用户名 2-20 位，密码至少 8 位；服务器用 scrypt 加盐哈希存储，明文不落盘。登录凭证为 7 天有效期的 httpOnly Cookie（网页）/ Bearer 令牌（APK），均带 HMAC 签名，可安全经隧道分发。

**安全机制**：注册 3 次/时/IP、登录 10 次/分/IP 限流；单账号连错 5 次密码锁定 15 分钟；改密/重置密码自动吊销所有设备旧令牌。回退开关：服务器以 `AUTH_ENFORCE=0` 启动可临时关闭联机登录门禁（灰度/回滚用）。

**忘记密码**（两种方式，无需邮件）：
- **恢复码**：注册成功时显示 10 组一次性恢复码（XXXX-XXXX），请当场截图保存；在登录界面「找回密码」输入任一未用恢复码即可重设密码（重设后恢复码全部换新）。
- **安全问题**：注册时可选设置；答对原题（不区分大小写）即可重设。

**云存档**：登录后本地进度变化自动防抖上传（2 秒），换设备登录后下载并按「进度只进不退」策略合并（层解锁/星级/最佳成绩/好感/合照取双方较大值）。冲突采用乐观锁：两端同时写时后写方收到 409 云端版本，本地合并后重试。

**数据位置**：账号数据存 `data/game.db`（SQLite，node:sqlite），签名密钥 `data/secret.key`——`data/` 已 gitignore。**水平扩容（负载均衡）**：令牌无状态（HMAC 自校验 + DB 内 token_ver 吊销），多实例只需共享 `data/` 目录或把 users/saves 迁到集中式 DB；限流计数为内存态，多实例下建议由网关统一执行。

## 安卓手机：安装与远程联机

**方式一 · 局域网（同一 WiFi，最快）**

1. 电脑运行 `node server.js`（防火墙已放行 8765 入站；未放行时以管理员执行 `netsh advfirewall firewall add rule name=onetwobubu-game-8765 dir=in action=allow protocol=TCP localport=8765`）。
2. 手机浏览器打开 `http://<电脑IP>:8765`（IP 见服务器启动日志，如 `http://192.168.118.108:8765`）即玩，虚拟触屏按键自动显示。
3. 要装独立 App：手机浏览器访问 `http://<电脑IP>:8765/deploy/onetwobubu.apk` 下载安装（需允许「未知来源安装」，debug 签名）。

**方式二 · 互联网异地（无需公网服务器）**

1. 房主电脑：先运行 `node server.js`，再双击 `deploy\启动互联网隧道.bat`，窗口内出现 `https://xxxx.trycloudflare.com` 公网地址（cloudflared 快速隧道，免注册；每次启动地址会变）。
2. 队友手机浏览器直接打开该链接游玩（联机地址自动填好）；APK 用户在「双人联机 → 服务器地址」填 `wss://xxxx.trycloudflare.com/ws`，连接成功后自动记住。
3. APK 也可经隧道分发：把 `https://xxxx.trycloudflare.com/deploy/onetwobubu.apk` 发给队友下载安装。

**方式三 · PWA 添加到主屏（免安装包，离线可玩）**

1. 手机浏览器打开游戏的 **https** 地址（即方式二的隧道链接；`http://局域网IP` 不满足安全上下文，Chrome 不显示安装入口）。
2. Chrome 菜单 →「安装应用 / 添加到主屏幕」→ 获得独立图标、全屏无地址栏运行。
3. 首次联网加载后 `sw.js`（网络优先 + 写穿缓存）即支持离线启动单人游玩；进度存 localStorage 不丢。更新代码后重开自动拉新；如需整体换缓存改 `sw.js` 顶部 `CACHE` 版本号。
4. 联机照常：https 页面自动用 wss；APK/离线壳内则手填服务器地址（见方式二）。

**安全提示**：隧道 URL 为随机域名、关窗即失效，天然限定了访问范围；联机建房/加入需登录账号（防陌生人蹭房），但房间码本身仍是唯一屏障，不要把房间码公开扩散。

**重新打包 APK**（改了游戏代码后）：`node deploy\make_www.js` → `npx cap sync android` → `cd android` → `gradlew.bat assembleDebug`，产物在 `android\app\build\outputs\apk\debug\app-debug.apk`（复制到 `deploy\onetwobubu.apk` 分发）。工程为 Capacitor 6 + Android SDK 34，需本机装好 JDK 17 与 `%LOCALAPPDATA%\Android\Sdk`。

## 开发者：代码结构

单页应用，拆分为 1 个 HTML + 1 个 CSS + 10 个浏览器 JS（共享同一全局作用域，无模块系统）+ 2 个 Node 服务端文件。`index.html` 中 `<script>` 的加载顺序即依赖顺序：

```
index.html   HTML 骨架 + <link> + 10 个 <script>
style.css    全部样式
   ↓ JS（按序加载，后者可用前者声明）
levels.js    关卡数据与配置：地图符号表、物理常量(TILE/GRAVITY/JUMP…)、
             LEVELS/THEMES/MAJORS、派生数组、合照清单
audio.js     WebAudio：音效(beep/sfx*) + 文件 BGM 两选项选曲(bgm/ 8 轨：专属 7 曲顺序播放
             / 原版循环，轨间交叉渐变) + 程序化背景音乐(旋律/贝斯/浪漫轨，文件不可用时的回退)
ui.js        界面：DOM 引用、showScreen 状态机、选关/地图/恋爱空间/纪念册/
             合照界面、高清渲染(DPR)、暂停、HUD
save.js      存档与好感：loadSave/persistSave、好感数值与称号、
             爱情任务线、纪念册数据、recordWin 与解锁推进
sprites.js   角色贴图：正/侧贴图加载、cutout() 抠图、皮肤切图
mechanics.js 物理与机关：stepPlayer/碰撞、按钮/门/箱子、移动平台/史莱姆/Boss、
             危险判定、胜利检查、评分、动画与相机
render.js    渲染：drawBackground/drawTiles/全部 draw*/drawPlayer/render
net.js       联机：net 状态对象/netSend、连接管理、主机广播、
             客机插值、联机状态条
auth.js      账号客户端：登录/注册/找回六面板、Cookie/Bearer 双通道、
             联机门禁跳转、云存档合并与防抖上传
game.js      核心编排：玩法调参常量、关卡载入、输入(键盘/触屏)、
             tick、主循环、交互事件绑定、启动
（服务端）
server.js    静态服务 + WS 中继：/api/* 交 server-auth；upgrade 解析 Cookie/Bearer
             绑 conn.uid；create/join 登录门禁；房间/快照转发不变
server-auth.js 账号内核：node:sqlite(users/recover/saves)、scrypt 口令哈希、
             无状态 HMAC 令牌+token_ver 吊销、限流与账号锁定、找回票据、
             云存档 rev 乐观锁；零第三方依赖
```

> ⚠️ `game.js` 末尾的「交互事件绑定 + 启动」段在加载时即执行，依赖前面所有文件的函数声明，位置不可前移。

**关卡扩展**：关卡是 48×10 字符画（符号含义见 `levels.js` 头部注释）。改关卡请编辑生成器 `_gen_levels.js`（含落地模拟 + 跳跃可达性校验），再依次运行 `node _gen_levels.js` 与 `node _inject_levels.js` 注入 `levels.js`，勿手改生成段。

**玩法调参**：协作判定距离、好感数值、Boss 几何等集中在 `game.js` 头部「玩法调参常量」区。

**质量与测试**

```
npm run lint    # ESLint 宽松规则（核心 no-undef 抓跨文件未定义引用）
npm test        # 一键串行运行 tests/ 下 17 个自动化脚本（16 个 CDP + auth_api，需先启动服务器；测试期建议 AUTH_RATE_LIMIT=0 启动，见 tests/_restart_server.ps1）
node tests/run_all.js love   # 只跑名字含 love 的脚本
```

测试基于 headless Chrome + CDP（`tests/cdp_*.js`），覆盖界面状态机、机关、多层流转、联机同步、存档兼容等。`_legacy/` 为已废弃的历史版本存档。

## 存档字段（localStorage key = `onetwobubu_save_v1`）

| 字段 | 含义 |
|---|---|
| `unlocked` | 已解锁到的层（扁平索引） |
| `best` / `stars` | 每层最佳评级 / 星级 |
| `subs` | 各主关每子层是否通过 |
| `bonusStars` | 首通奖励星总数 |
| `photos` | 已解锁合照下标数组 |
| `love` / `loveStats` | 好感度 / 水晶·弹跳·护盾·牵手累计 |
| `loveTiers` / `heartLv` | 各任务家族已达阶数 / 每关水晶已计数次数 |
| `album` | 纪念册（相识日期、打卡、时光轴、纪念日） |
| `settings` | 音效/音乐/音量/HUD 开关/触屏按键（auto/on/off） |

旧档缺字段时加载会自动补默认值，多余字段忽略。
